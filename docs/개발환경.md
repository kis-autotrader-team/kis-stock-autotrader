# 개발 환경 (두 사람 모두 동일하게 맞출 것)

두 사람의 환경이 다르면 "내 PC에선 되는데" 문제로 2주 일정이 무너집니다. 아래 버전을 **정확히** 맞춥니다.

## 1. 기준 환경

2026-11-23에 팀원 PC에서 확인한 버전을 기준으로 정했습니다.

| 항목 | 기준 | 확인 명령 | 비고 |
|---|---|---|---|
| OS | Windows 11 (x64) | `winver` | 프로그램 대상이 Windows라서 개발도 Windows로 통일 |
| Python | **3.12.10** | `python --version` | 3.13 이상, 3.11 이하 사용 금지 |
| 패키지 관리 | **uv** (최신 안정판) | `uv --version` | 가상환경 생성과 의존성 잠금(`uv.lock`)을 한 번에 처리. 한투 공식 샘플도 uv 사용 |
| Git | 2.55 이상 | `git --version` | |
| GitHub CLI | 2.101 이상 | `gh --version` | PR 생성·리뷰용 |
| 에디터 | VS Code 1.147 이상 | `code --version` | |
| 터미널 | VS Code 내장 터미널 (PowerShell) | | 명령 예시는 PowerShell 기준 |

> 버전을 올리고 싶으면 혼자 올리지 말고 PR로 이 문서와 `.python-version`을 같이 바꿉니다.

## 2. 설치 순서

### 2-1. Python 3.12.10
1. https://www.python.org/downloads/release/python-31210/ 에서 **Windows installer (64-bit)** 다운로드
2. 설치 첫 화면에서 **"Add python.exe to PATH" 체크**
3. 새 터미널에서 `python --version` → `Python 3.12.10` 확인

### 2-2. uv
```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```
터미널을 다시 열고 `uv --version` 확인.

### 2-3. Git, GitHub CLI
```powershell
winget install --id Git.Git -e
winget install --id GitHub.cli -e
gh auth login     # GitHub.com → HTTPS → 브라우저 로그인
```

### 2-4. Git 공통 설정 (둘 다 동일하게)
```powershell
git config --global user.name "본인 GitHub 이름"
git config --global user.email "GitHub에 등록한 이메일 (noreply 주소 권장)"
git config --global core.autocrlf true      # Windows 줄바꿈 처리
git config --global init.defaultBranch main
git config --global core.quotepath false    # 한글 파일명 깨짐 방지
```
- 이메일은 GitHub 설정의 `...@users.noreply.github.com` 주소를 쓰면 개인 이메일이 커밋에 남지 않습니다.

### 2-5. VS Code 확장 (둘 다 동일하게 설치)

| 확장 | ID | 용도 |
|---|---|---|
| Python | `ms-python.python` | 실행, 디버깅 |
| Pylance | `ms-python.vscode-pylance` | 자동완성, 타입 검사 |
| Ruff | `charliermarsh.ruff` | 린트 + 포맷 (저장 시 자동 정리) |
| autoDocstring | `njpwerner.autodocstring` | Google 스타일 docstring 뼈대 생성 |
| Markdown All in One | `yzhang.markdown-all-in-one` | 명세서·작업보고 작성 |
| GitHub Pull Requests | `github.vscode-pull-request-github` | VS Code 안에서 PR 리뷰 |

설치 명령:
```powershell
code --install-extension ms-python.python
code --install-extension ms-python.vscode-pylance
code --install-extension charliermarsh.ruff
code --install-extension njpwerner.autodocstring
code --install-extension yzhang.markdown-all-in-one
code --install-extension github.vscode-pull-request-github
```

## 3. 프로젝트 받기와 실행 (리포 생성 후)

```powershell
gh repo clone <조직또는계정>/<리포이름>
cd <리포이름>
uv sync                  # .python-version과 uv.lock 기준으로 가상환경 생성 + 설치
uv run pytest            # 테스트 실행
uv run ruff check .      # 린트
uv run ruff format .     # 포맷
```
- 패키지 추가는 반드시 `uv add <패키지>`로 합니다. `pip install` 금지 (lock 파일에 안 남아서 환경이 갈라짐).
- `uv.lock`은 **커밋합니다.** 두 사람이 똑같은 버전을 쓰게 하는 핵심 파일입니다.

## 5. 공통 규칙

- **인코딩:** 모든 파일 UTF-8. 파이썬에서 파일 열 때 `encoding="utf-8"` 명시.
- **시간:** 내부 저장은 모두 UTC 또는 시간대 포함(`datetime` aware). 국내장은 `Asia/Seoul`, 미국장은 `America/New_York` 기준으로 판단. 서머타임 계산을 직접 하지 않습니다.
- **돈 계산:** `float` 금지, `decimal.Decimal` 사용.
- **로그:** `print` 금지, `logging` 사용. 로그에 앱키·계좌번호를 남기지 않습니다.
- **비밀값:** `.env`는 git 제외. 예시 파일 `.env.example`만 커밋(값은 비움).
- **절전:** 연속 운영 테스트(10~13일차) 때는 Windows 절전·자동 업데이트 재시작을 꺼 둡니다.
